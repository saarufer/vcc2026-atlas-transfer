# 深度学习探索

（[English](DEEP_LEARNING.md)）

最终管线是结构化的图谱迁移模型，不是端到端的深度网络。做出这个选择之前，我们搭建了两条深度学习路线，都在 GPU 上训练，并在同一套协议下与迁移基线做了比较。本文记录这些实验：做了什么、怎么检验、为什么两条路线都没有进入最终模型。

硬件：开发用单卡 RTX 5090（32 GB，sm_120），所有设计都同时核对了能否装进 16 GB V100。软件：PyTorch 2.x + CUDA 13，FP16 混合精度。

---

## 1. 为什么要试深度学习

迁移管线把其他细胞系实测的响应放进目标细胞系。这对响应的方向（PDS）很有效，但它学不到响应如何*随细胞背景变化*。早期采样修正 MSE 一直停在基线附近，这提示我们可能需要一个以目标系为条件、直接建模绝对表达的模型。我们从两条路线检验了这个假设：

1. **STATE**：已发表的基于集合的扰动 Transformer，用公开 CRISPRi 数据重新训练。
2. **Intervention-VC**：我们自研的条件 flow-matching 生成器，外加一个学习式的源融合模型。

## 2. 路线 A：STATE（集合 Transformer 扰动模型）

### 2.1 搭建
- 模型是开源的 STATE 转移模型（Arc Institute，`arc-state`），运行在隔离环境里，并为兼容检查点固定了 `transformers` 版本。
- 架构约 1.55 亿参数：
  - 扰动编码器（1.4M）；
  - 基础细胞编码器（11.9M）；
  - 双向 Llama 主干（50.4M）；
  - 输出投影（13.3M）；
  - 全基因上/下投影（78.4M）。
- **数据契约：**
  - 所有数据集统一到同一个基因轴和统一的 `obs` 字段。
  - 表达统一归一化为 log1p(CP10k)。否则两个源之间 2.9 倍的测序深度差异会主导信号。
  - 细胞系背景由基础（对照）细胞编码。细胞类型 one-hot 无法泛化到未见过的细胞系。
- **均衡采样器**：按 context → 靶点 → 细胞分层，避免最大的图谱主导训练。
- 100 步冒烟测试：19 it/s，loss 8.21 → 8.15。完整训练约占 3.4 GB 显存。

### 2.2 评估协议
- **留一细胞系（LOCO）。** 每个训练折都完全排除被留出的细胞系。
- 模型预测单细胞，聚合成伪批量后在 log 空间与真值比较。两种读出：
  - **直接读出**：直接用预测的表达；
  - **Δ 重锚定**：把预测的响应叠加到留出系的真实对照均值上。
- 两种读出都报告为"相对平均响应基线的误差比"，小于 1 表示胜过基线。
- 预注册的判决规则：模型必须胜过**同样排除留出系的 donor 迁移基线**。只胜过朴素基线不算数。

### 2.3 结果

| 折 | 训练数据 | 直接 | 重锚定 | 判断 |
|---|---|---|---|---|
| 1 | H1（151 个扰动）→ K562 | – | 1.41 → 1.65（越训越差） | 失败，源太少 |
| 2 | K562（6,611 个扰动）→ H1 | 4.10 | 1.07 | 重锚定必不可少 |
| 2（拆分） | 见过 / 未见靶点 | – | 1.071 / 1.070 | 开放词表成立 |
| 决定性 | K562 + HCT116 → HEK293T | – | **1.381**，donor 为 **1.219** | **STATE 更差** |

这些结果说明：
- **重锚定必不可少。** 直接读出带着很大的绝对水平误差（4.10）。只有把预测的响应叠加到真实对照细胞上，结果才能用。
- **源的丰富度比架构更重要。** 用 151 个扰动训练失败，用 6,611 个扰动训练就接近了基线。
- **开放词表泛化成立。** 训练中从未见过的靶点，预测得和见过的一样好（1.070 vs 1.071）。用基因嵌入去覆盖未见扰动的思路是对的。
- **决定性实验是阴性。** 我们选了最公平的一折：同平台、相近的上皮谱系。在这一折上，STATE 比 donor 迁移差 13%。在 2,500 个靶点上做配对 bootstrap，差距为 +0.162（95% CI [+0.158, +0.166]），98% 的靶点上 STATE 更差。增加第二个训练 context（HCT116）几乎没有帮助。
- **在真实的六项打分器上**，STATE 相对迁移管线平均 −0.156（PDS −0.037）。
- **预训练权重。** 公开的检查点经核查只是演示权重。我们还评估了把冻结的基础模型细胞嵌入（SE-600M）作为输入，结论不变。

这条路线随后封存，结论措辞是：*在公开数据规模、全基因重锚定的条件下，集合 Transformer 没有为 donor 迁移带来增值*。这是对当前数据条件的判断，不是对这类方法的普遍否定。

### 2.4 副产品：差异表达校准
我们用官方 DE 定义诊断了模型输出：
- CPM、BH 校正的 Wilcoxon 检验；
- 基因宇宙限定为对照 CPM > 5；
- 排除靶基因。

诊断发现，预测出的 DE 基因约多出 8 倍。原因之一是**通用塌缩**：同一批约 86 个基因在一半以上的扰动里都被判为显著。追溯下来，根源是确定性发射：把一个小而一致的倍数变化乘到几百个细胞上，秩检验总会判它显著。加入随机发射（异质性或负二项）就消除了这个伪影。但 DE 校准的神谕上限很小（Jaccard 0.048 → 0.064），所以没有把它作为单独的提分杠杆。这个经验延续到了最终的发射器里：发射噪声本身也是模型的一部分。

## 3. 路线 B：Intervention-VC（flow-matching 生成器与学习式融合）

### 3.1 设计
扰动细胞的条件生成模型：

  P(X_pert | C_target, g, m, d, t)

其中 C_target 是目标系的一组对照细胞，g 是靶基因，m 是模态，d 是剂量，t 是时间。

- **ContextEncoder**：对对照细胞做注意力池化的集合编码器。
- **InterventionEmbed**：学习式的基因嵌入，加上模态、剂量、时间嵌入。
- **VelocityNet**：覆盖全部 18,533 个基因的 flow-matching 速度场。
  - 朴素的基因×基因注意力，单细胞单层就要约 5 GiB，32 个细胞约 164 GiB。
  - 我们让基因通过 **M = 128 个学习式模块 token** 相互作用（M×M 注意力）。基因维只出现在输入和输出投影里。
- **损失** = flow-matching + 群体均值 + 排序项，并配有实测基因掩码，使数据集里缺失的基因不参与损失。
- **可移植性**：
  - FP16 AMP 加 GradScaler，损失归约用 FP32；
  - 不依赖 BF16 和 FlashAttention-2，可在 V100（sm_70）上运行。

### 3.2 阶段 A：显存剖析与验收
模型共 7,010 万参数（d_model 512，6 层生成器，2 层 context 编码器）。验收测试：
- T1：前向输出覆盖全基因；
- T2：141 个参数张量都有梯度；
- T3：改动未实测的基因，损失不变（Δloss = 0），说明掩码确实进入了损失；
- T4：FP16 AMP 一步训练后梯度范数有限。

四项全部通过。显存峰值在真实训练步上实测：

| 批量（episode）× 细胞数 | 峰值显存 |
|---|---|
| 8 × 32 | 1.50 GB |
| 32 × 64 | 1.64 GB |
| 32 × 128 | 1.80 GB |
| 64 × 64 | 2.41 GB |

所有配置都能装进 16 GB V100，余量很大。这一阶段抓到一个 bug：初版把 M×d_model 直接展平投影到基因，参数量达到 12 亿。修复方法是先池化回 d_model，再做输出投影。

### 3.3 阶段 B：群体模型
- **Episode 构建器。** 读取原始计数，按 context → 靶点 → 细胞采样，并在不同 epoch 之间轮换细胞。
- **群体分支。** 用 context 谱对靶点嵌入做 FiLM 调制，再解码出 log 倍数变化（context，靶点）。
  - 3,960 万参数，在 12 个公开 context（64,616 个 episode）上训练，损失为加权 MSE 加同 context 内的 InfoNCE。
  - 打乱靶点的负对照得分为随机水平，证明模型确实用到了扰动身份。
  - 但在留出系上仍低于迁移基线（辨识度 0.647 vs 0.715）。
- **加性分解**为共享靶点效应加 context 交互项（交互惩罚 + context dropout）：没有改进。
- **诊断。** 由学到的嵌入重建出的预测，比原始源数据模糊（0.59–0.64 vs 0.74）。差距来自**每个靶点细节的丢失**，而不是 context 泛化。
- 训练坑：输出层全零初始化，加上 L2 归一化的 InfoNCE，产生了约 1e12 的梯度，GradScaler 于是每一步都跳过更新。改用小标准差初始化并加 epsilon 后解决。

### 3.4 阶段 C：学习式参考融合
这个模型不重新生成响应，而是学习**如何给各源的实测响应加权**：
- α = softmax(MLP[查询谱，源谱，源响应，强度，留一一致性，覆盖度])；
- 外加一个可学增益；
- 用留一 context 元学习训练。

结果：
- 这是第一个验证集 MSE 低于零预测的模型（0.1008 vs 0.1068），验证集辨识度从 0.80 提高到 0.86。
- 为了有一个快速、计入噪声的评估，我们做了 **PDSSim**：在伪批量层精确模拟计数稀释（二项分布之和仍是二项分布），秒级完成，复现了真实打分器的排序。它也揭示了单次真实评估的种子标准差约为 0.015，所以之后只依据多种子配对比较做决策。
- 与手调融合做 20 种子配对比较：
  - HCT116 折：+0.003 ± 0.002；
  - HEK293T 折：−0.004 ± 0.002；
  - 两折都明显优于均匀平均（+0.02）。
- 改用与官方 PDS 几何对齐的训练目标（删除靶基因列、同 context 余弦排序）后，没有进一步提升。
- 按研究整组留出的测试表明，学到的权重在部分谱系上比手调路由更稳健，但平均并不更好。

结论：学习式融合仅靠数据就达到了手调水平，但没有超越。它的几条经验进入了最终模型：
- 多样的多个源胜过任何单一源；
- 留一一致性是安全的源加权方式；
- 可信度按（靶点，基因）学习，比按源学习更好。

最后这一点，就是最终管线里梯度提升可信度模型和值模型的由来。

## 4. 最终管线中的 GPU 使用
- **PIE** 零样本预测（Arc 的扰动模型）在 GPU 上运行，以每个目标系自己的对照细胞为条件。
- **本地打分**用 `cell-eval2` 的 GPU DE 引擎。我们核对过 GPU 和 CPU 引擎在六项指标上三位小数完全一致，所以本地 DE 指标和官方引擎一致。
- 也试过用神经网络替代梯度提升模型，没有帮助（例如用对比学习 MLP 估计可信度权重）。

## 5. 经验
1. **在公开数据规模下，结构胜过容量。** 同模态的 CRISPRi 细胞系不到十个，重叠靶点只有几千个。1.55 亿参数的 Transformer 和 7,000 万参数的生成器，都输给了直接迁移实测响应。
2. **预测响应，而不是状态。** 所有有效的变体，都是把预测的*变化*重锚定到目标系的真实对照细胞上。
3. **数据丰富度起决定作用。** 训练扰动从 151 个增加到 6,611 个，重锚定误差从 1.65 降到 1.07。增加 context 只有在谱系和平台有信息量时才有帮助。
4. **未见靶点的泛化不是瓶颈。** 见过和没见过的靶点得分相同。瓶颈在于响应在不同细胞系之间变化了多少。
5. **评估本身是模型的一部分。**
   - 保留靶基因自身的代理指标会把方法排错序。
   - 单种子评估分辨不出小于 0.03 的差异。
   - 预注册的判决规则和配对多种子检验，让我们没有把噪声当成提升。
6. **发射噪声很重要。** 确定性发射会在基于显著性的指标上制造伪影。真实的噪声能消除伪影，但也会淹没弱信号，所以发射器和预测器必须一起调。

我们预计，当更大的私有图谱或新发布的图谱覆盖更多细胞系时，这个平衡会改变。这里的架构（集合编码的 context、模块 token 速度场、学习式融合）已经为那种数据条件做好了准备。
