# vcc2026-atlas-transfer

**基于多图谱迁移与矩匹配计数发射的未见细胞系 CRISPRi 响应零样本预测**
队伍 *Saarufer*，Arc Institute Virtual Cell Challenge 2026（[English](README.md)）

|---|---|---|---|---|---|---|---|

本方法**只用公开扰动数据**，不训练端到端深度模型。每个预测都是把公开图谱里实测的 CRISPRi 响应迁移到目标细胞系，再生成整数计数的细胞。

---

## 1. 任务

有三个细胞系，在任何公开数据里都没有被扰动过。要为其中每个细胞系的 300 个 CRISPRi 敲低各预测 400 个单细胞（原始整数计数，18,533 个基因）。目标侧唯一的输入是该细胞系自己的非靶向对照细胞。评分用 `cell-eval2`（`vcc2026` 预设）的六项指标。每项都做了标定："对所有靶点都预测该细胞系真实的平均扰动响应"记 0 分，"半重复实验"记 1 分。总分是六项的平均。

主办方没有给出细胞系身份。我们用对照细胞的表达谱和 CCLE 比对，识别出验证集 A/B/C 为 Jurkat、HeLa、CAL-33，最终 D/E/F 为类 MOLM-13（AML）、U-87 MG（胶质母细胞瘤）和成纤维/间充质样细胞系。

## 2. 方法概览

```
公开 CRISPRi 图谱 ──► 各源效应(中心化) ──► 全源方向投票 ──► 可信度权重(HGB)
                                              │                  │
                   PIE 零样本先验 ──────────► 融合 ◄── 值模型(HGB)
                                              │
        目标系对照细胞 ──► 对照主成分杠杆、低表达门控、逐靶幅度 κ
                                              │
            MSE 预算校准(仅用对照细胞) ──► 幅度
                                              │
                基于真实对照细胞的双矩发射 ──► 每靶 400 个整数计数细胞
```

### 2.1 数据源
300 个靶点的响应取自公开的 CRISPRi Perturb-seq 图谱：
- **融合源：** Replogle K562 全基因组、X-Atlas/Orion HCT116 与 HEK293T、Arc H1（VCC 2025 数据）、DLD-1（GSE337988）。
- **投票源：** VIPerturb-seq K562 全基因组（Flex）、KOLF2.1J iPSC 全基因组图谱、HipSci iPSC CRISPRi 图谱、H1 全基因组（GSE295214）、McFaline-Figueroa 胶质瘤激酶组筛选（A172/T98G/U87MG）、Jiang 等的六细胞系筛选。
- **先验：** Arc 的 PIE 零样本模型、CD4 T 细胞 CRISPRi、启动子邻近基因表（CRISPRi 会同时沉默和靶点共享启动子的基因）。

每个源都先整理成逐靶点的伪批量统计量（见 `builders/`）。响应在两个空间里分别计算：单细胞 log2 倍数变化通道和伪批量 Δ 通道。

### 2.2 效应构建（`pipeline/predict_amp.py`）
1. **源内中心化。** 每个源都减去自己所有靶点的平均响应，以去掉实验室和平台特有的公共成分，这部分无法在实验室之间迁移。
2. **全源方向投票。** 每个源贡献自己响应的单位向量，按 √(细胞数) 加权。投票结果以 λ = 0.5 混入两个通道，并保持每个靶点的范数不变。源的多样性远比单个源的精度重要。
3. **逐靶幅度 κ。** 用源之间两两余弦的均值衡量一个靶点的响应有多容易迁移，幅度按 κ^0.5 缩放（限制在 [0.5, 3]）。
4. **可信度权重。** 用留出细胞系训练的梯度提升分类器，根据 12 个与尺度无关的特征（源间一致度、z 值、表达量、投票排名等）预测每个（靶点，基因）的投票方向判对的概率 p。权重取 (0.5 + p)^5，并恢复范数。
5. **值模型。** 在同一组特征上训练梯度提升回归器，按基因跨靶点中心化后，以 λ = 0.2 混入伪批量方向。
6. **PIE 先验。** Arc PIE 的预测以 w = 0.5 混入单细胞通道、以 w = 0.1 混入伪批量通道，只作用于表达的基因。PIE 以目标系自己的对照细胞（log1p CP10k）为条件；把细胞系文本键换成相近的代理系，结果几乎不变。
7. **对照主成分杠杆。** 对最弱的 80% 靶点，伪批量效应沿目标系对照细胞的前 50 个主成分方向降权。这些方向承载的是通用变异，会让弱靶点彼此相似，从而降低区分度（PDS）。
8. **低表达门控**（CPM 5–50）作用于伪批量通道；**power-lift 和按置信度加权的秩次塑形**作用于单细胞通道。它们塑造的是差异表达指标看到的单细胞分布，与伪批量均值互不干扰。

### 2.3 按 MSE 预算定幅度
`cell-eval2` 的采样修正 MSE 会从每个扰动的误差里扣除一个修正项。这个修正项受预测自身跨扰动离散度 *B* 的限制，上限我们称为 *claim*。因此，在 claim 以内，预测里放进去的能量是"免费"的，MSE 最优的幅度满足 **B ≈ claim**。claim 只取决于 400 细胞组的 jackknife 采样噪声，**只用目标系的对照细胞就能估计**（`scoring/claim_from_controls.py`）。在一份真实的 Arc 平台数据上，扰动组和对照组的采样噪声几乎相同（比值 1.03）。我们为每个细胞系设定幅度，使 B = 0.98 × claim。这样就用一条可以在没有反馈的情况下迁移到新细胞系的规则，取代了靠排行榜调出来的幅度。

### 2.4 计数发射
每个靶点的 400 个细胞都以目标系的真实对照细胞为模板（两两池化）。双矩拟合同时匹配两样东西：单细胞平均 CPM（单细胞通道）和按深度加权的伪批量（伪批量通道）。然后整数化，并保留每个细胞的测序深度。因为两个通道分开拟合，差异表达类指标和伪批量类指标可以各自优化。

## 3. 主要认识

- **源的多样性胜过单源精度。** 对多个源做等权的单位向量投票，一直优于逆方差元分析、按相似度加权源，以及上调最近源的权重。把权重集中到一个源上，会丢掉投票带来的噪声抵消。
- **共模响应无法跨实验室迁移。** 一个细胞系在所有扰动上的平均响应，是 MSE 误差中最大的一块。用其他实验室的图谱来估计，与真值的余弦只有约 0.2–0.45，在评分所用的 log1p(5e4·CPM) 空间里接近 0。即使是同一细胞系、但来自不同实验室的源也一样；即使用对照谱特征去建模它相对图谱平均的偏离，也一样。把它注入预测只能略微改善 MSE，却会损害扰动区分度。
- **用神谕测试台衡量平台模拟。** 把一份真实 Arc 数据一半的*真实*伪批量喂进发射器，用另一半打分，就能单独测出发射这一步造成的损失。结果是：PDS、reach、nmae 都达到了重复实验的水平，官方 MSE 也不受发射方差的限制。差异表达显著性（jac、fid）确实存在模拟差距，但在完美生物学下能缩小这个差距的发射器，换成真实预测后反而让分数下降：真实的单细胞噪声会淹没微弱而不完美的信号。
- **"测量量"的选择很重要。** 把源效应改写成有符号秩、噪声单位（z 值）或按敲低效力归一化之后，迁移效果都不如简单的单位向量。方向信号主要由少数大效应基因承载。
- **没有反馈时的验证。** 最终阶段没有分数反馈。我们用此前的官方分数校准了本地折（H1 稀释到官方深度、HCT116、K562-Flex）。有两个本地信号能可靠地预测官方变化：HCT116 上伪批量 MSE 变化的符号，以及 H1 上 PDS 变化的符号。只在本地差异表达指标上出现的提升，在官方结果里留不住。我们只采纳同时通过这两个信号的改动。完整的消融审计显示，8 个调过的组件里有 7 个在一个从未用于调参的折上稳健，之后我们冻结了最终模型。

数据来源见 [DATA_SOURCES.md](DATA_SOURCES.md)。深度学习实验（STATE 重训、flow-matching 生成器、学习式融合）及其未被采用的原因，见 [docs/DEEP_LEARNING_zh.md](docs/DEEP_LEARNING_zh.md)。

## 5. 复现

1. 下载比赛的对照细胞（`vcc datasets download controls-final`）和上面列出的公开图谱，放到 `vcc_data/`（路径见 `builders/` 中各脚本）。
2. 用 `builders/` 中的脚本为最终靶点面板构建源统计，放进一个数据目录。在这个目录里，`context_A/B/C.h5ad` 链接到 D/E/F 的对照文件。
3. 用最终配置运行预测：
   ```bash
   set -a; source configs/final.env; set +a
   python pipeline/predict_amp.py --data-dir <data_dir> --output pred.h5ad
   python scoring/relabel_final.py pred.h5ad pred_DEF.h5ad        # A/B/C -> D/E/F 标签
   vcc prep pred_DEF.h5ad -g gene_names.csv --perts pert_counts.csv -o prediction.vcc
   ```
   所有功能都由环境变量控制；`configs/final.env` 里没有列出的开关都是关闭的。管线是确定性的：我们重新运行后，逐字节复现了提交的文件。

依赖：numpy、scipy、pandas、anndata、h5py、scikit-learn、joblib、pyarrow（`pipeline/requirements.txt`）；本地打分需要 `cell-eval2`。
